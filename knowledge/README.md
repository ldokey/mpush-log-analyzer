# 해결 사례 데이터 계약

schema/case.schema.json에 사례 구조가, schema/signal_catalog.json에 매칭 코드가 정의되어 있습니다.
별도 AI는 이 두 파일을 먼저 읽고 사례당 한 JSON 파일을 생성해야 합니다.
신규 사례는 검토 대기(inbox)에만 보관하고, 승인 사례(approved)는 별도 검토 후 관리합니다.
Stage 1은 JSON 형식과 민감정보만 검사하고 파일의 자동 등록/매칭/승인은 수행하지 않습니다.
고객 개인정보, 서버 주소, 토큰 및 인증키, 실제 메시지 내용, 원본 로그를 포함하지 마세요.
개인정보가 들어 있는 JSON은 승인 대상에서 제외합니다.
